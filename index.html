操作说明

移动节点按住节点拖动（子节点一起动）
调整排序按住节点拖到同级节点的上方/下方间隙（出现蓝色插入线）松手即可重排顺序；也可用 Alt+↑/↓ 或右键菜单
更换上级 / 左右换边把节点拖到另一个节点中心松手 → 连整棵子树改挂到它下面；中心节点的一级分支可直接拖到中心另一侧自由换边
加子节点 / 左侧节点选中后 Tab / Enter，或点节点外侧绿色 ＋；悬停/选中中心节点点其左侧 ＋（或 Shift+Tab）可在左边加分支
直接输入替换单击选中节点后直接打字，将自动进入输入状态并全部替换该节点原内容
编辑 / 局部选取双击节点或点「✎ 编辑」进入全选编辑；单击文本切入光标输入，拖拽或双击词组局部选取内容；Enter 确认
回撤 / 重做Ctrl+Z 回撤上一步操作，Ctrl+Y 或 Ctrl+Shift+Z 重做（工具栏也提供按钮）
删除选中后 Del（含子节点，会先确认）
备注Alt+N 或点「📝 备注」→ 右侧面板写细节；节点右下出现 ≡ 表示有备注
标记颜色点击工具栏色点标记或清除颜色
待办Alt+T 或点「☐ 待办」循环：无 → 待办 ☐ → 进行中 ◐ → 完成 ☑
自由连线与箭头点「🔗 连线」或按 Alt+L 进入连线模式（再点一次退出）：支持点击或直接拖拽连接两个节点；点击任意连线可选中它，拖动起止圆点调位置、拖动中间菱形或滑块调曲率，支持切换箭头（单向/双向/反向/无）、虚实线、颜色与删除
折叠/展开点节点外侧折叠图标或数字徽章（或按 Space）；开启「逐层展开」后只展开该节点，子节点保持折叠；右键节点可选择展开方式
一键按层级折叠使用画布左上角「折叠子集」栏一键折叠指定层级的所有子集（或 Alt+0~9，Alt+A 全部展开）
平移 / 缩放空白处拖动 / 滚轮（或右下角 ＋－）
新建点「＋ 新建」清空画布，从「中心主题」开始（会先确认，防误覆盖）
本地导入点「⬆ 本地导入」，或把 .mmap / .xmind / Markdown 大纲 .md / .json / 单文件 .html 拖进窗口
本地化与断点续存无需登录，所有导图与断点草稿均100% 自动暂存在本机浏览器中；刷新或重新打开会提示选择「继续上次编辑 / 新建空白图 / 打开本机文件」
导出格式点「⬇ 导出到本地」选：.mmap 无损往返（工具原生，导回最准）；.md Markdown 大纲，给人/给 AI 读最省事，能导回（备注以引用块原样回来）；.json 通用 JSON；.xmind 与 XMind 桌面版互通；.html 单文件离线版，双击就能看
