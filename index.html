操作说明

移动节点按住节点拖动（子节点一起动）
更换上级把节点拖到另一个节点身上松手 → 连整棵子树改挂到它下面；悬停时目标亮绿框。不能拖到自己子孙上
加子节点 / 同级选中后 Tab / Enter，或点节点右侧的 ＋
改名双击文字，或 F2；Enter 确认
删除选中后 Del（含子节点，会先确认）
备注N 或点「📝 备注」→ 右侧面板写细节；节点右下出现 ≡ 表示有备注
标记颜色选中后按 1~4，或点工具栏色点；0 清除
待办T 循环：无 → 待办 ☐ → 进行中 ◐ → 完成 ☑（完成后文字加删除线）
跨分支连线L 或点「🔗 连线」进入连线模式 → 点目标节点即连上；点虚线可删除；Esc 退出
折叠/展开点节点左侧的小圆点
平移 / 缩放空白处拖动 / 滚轮（或右下角 ＋－）
新建点「＋ 新建」清空画布，从「中心主题」开始（会先确认，防误覆盖）
打开 / 拖入把 .xmind / .md / .json / .html 拖进窗口松手，或点「📂 打开文件」
本地导入点「⬆ 本地导入」，或把 .xmind / Markdown 大纲 .md / 本工具导出的 .json / 单文件 .html 拖进窗口
云端保存Ctrl+S 或点「💾 云端保存」。存到哪儿，取决于从哪儿打开：从服务器文件库打开 → 写回 maps/<名称>.mmap；新建/未命名 → 先问你文件名，再存服务器；从本机拖入/打开的文件 → 浏览器不允许网页直写本机原文件，会下载同名 .mmap 到下载目录，自己覆盖原文件即可
历史版本每次「💾 云端保存」都会留一份快照，编辑中每 3 分钟自动再留一份（每张图最多 30 份）。点「🕘 历史版本」→「恢复」把任意一份放回画布（恢复 ≠ 保存，回画布后还要点「保存」）
自动保存改动只自动存草稿（本地浏览器 + 服务器 draft.json），刷新或崩溃后可「继续上次编辑」；不会覆盖你的文件
多用户左上角「👤 空间」就是你的身份：图/历史/草稿按空间隔离，别人的列表里看不到你的；换设备用「专属链接」进同一空间，共用电脑请点「退出空间」
导出格式点「⬇ 导出到本地」选：.mmap 无损往返（工具原生，导回最准）；.md Markdown 大纲，给人/给 AI 读最省事，能导回（备注以引用块原样回来）；.json 通用 JSON；.xmind 与 XMind 桌面版互通（颜色/连线会丢）；.html 单文件离线版，双击就能看、不需要服务器
